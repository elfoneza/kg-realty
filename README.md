# Мониторинг рынка недвижимости Кыргызстана

Собирает объявления о продаже квартир и коммерческой недвижимости (офисы, магазины, склады…)
с lalafo.kg, house.kg, stroka.kg, bishkek.etagi.com, elitka.kg и каталог ЖК elitka.kg в одну базу.

## Команды
```bash
uv run python -m kg_realty collect               # свежие объявления (первые 3 стр. каждого сайта)
uv run python -m kg_realty collect --mode full   # полный обход (~1400 страниц, ~25–30 мин)
uv run python -m kg_realty complexes             # каталог ЖК с классами жилья (~3 мин)
uv run python -m kg_realty collect -s lalafo_com,house_com,stroka_com,etagi_com --mode full   # только коммерция
uv run python -m kg_realty districts             # пересчитать единые названия районов
uv run python -m kg_realty stats                 # что лежит в базе
uv run python -m kg_realty schedule              # по расписанию: каждые 15 мин свежее, в 03:00 полный обход, в 05:30 ЖК
```

## Дашборд
```bash
uv run streamlit run dashboard.py      # откроется http://localhost:8501
```
Вкладка «Аналитика»: средняя/медианная цена по районам (новостройка и вторичка) и карта,
какая площадь квартир и офисов пользуется наибольшим спросом, сравнение вторички и новостроек,
в каком году сдаёт объекты большинство застройщиков, список идей для дальнейшего анализа.

Остальные вкладки: обзор рынка (авто-выводы, комнатность, состояние, серии, распределение цен),
районы, новостройки и застройщики (каталог ЖК elitka по классам, сдача по годам),
динамика (новые/снятые, медиана $/м² по дням, изменения цен), сравнение источников,
выгодные предложения (дешевле медианы района). Фильтры: город, сайты, комнатность, сегмент, продавец.
Квартира, выставленная на нескольких сайтах, в итогах считается один раз.

## База (`data/realty.db`, SQLite; для PostgreSQL задайте `DATABASE_URL`)
- `listings` — объявления в едином формате: комнаты, площадь, этаж, серия, ремонт, цена в сомах и $, $/м²,
  город, район, координаты, тип продавца, ЖК, отклонение от рынка (house, stroka), старая цена (lalafo, house).
  `is_active=0` + `removed_at` — объявление пропало при полном обходе (косвенный признак продажи).
  `dup_group` — одна и та же квартира на разных сайтах.
  `property_type` — flat или тип коммерции: office, retail, free_purpose, warehouse, catering, hotel, production, business.
  `district_norm` — единое название района: текст сайта в нормальной форме, а где его нет (house.kg, etagi) —
  район из адреса или по 9 ближайшим подписанным объявлениям в радиусе 1,2 км.
- `price_history` — каждое изменение цены объявления.
- `complexes` — ЖК: класс, застройщик, $/м², цены по комнатности, срок сдачи, рассрочка, ссылка на реестр Минстроя.
- `complex_price_history` — изменения $/м² по ЖК.
- `runs` — журнал запусков и ошибок.

## Нормализованные значения
- `condition`: pso (под самоотделку), euro, designer, good, average, unfinished
- `series`: elitka, 104, 105, 106, 105_improved…, khrushchevka, stalinka, malosemeyka, other
- `seller_type`: owner, agency, developer (пусто — сайт не указал)
- `rooms`: 0 = студия

## Ограничения
- Берутся только обычные страницы сайтов; разделы, закрытые в robots.txt (API, ajax), не используются. Пауза 2 с между запросами к одному сайту.
- lalafo: комнаты, площадь, этаж и ремонт берутся из заголовка, у части объявлений с произвольным заголовком их нет.
- etagi и stroka показывают цену только в сомах, $ пересчитывается по курсу из объявлений других сайтов.
- house.kg: название ЖК пока не подтягивается (есть только его код `complex_source_id`).
- «Индекс спроса» — косвенная оценка по просмотрам/звонкам в день, а не по сделкам. Точнее станет
  «доля снятых» и срок до снятия — после нескольких недель полных обходов.
- Срок экспозиции на lalafo занижен: продавцы переподают объявления, и дата публикации обновляется.
- Если сайт поменяет вёрстку, его парсер вернёт 0 объявлений, а ошибка запишется в `runs`.

## Онлайн-версия (GitHub + Streamlit Community Cloud)
- **Сбор** — `.github/workflows/collect.yml`: каждый час свежие объявления, в 03:00 (Бишкек) полный обход,
  в 05:30 каталог ЖК. Ручной запуск: вкладка Actions → collect → Run workflow.
- **lalafo.kg** в облаке не собирается: сайт блокирует серверы дата-центров (403). Его данные в базе — архив
  на 16.11.2026; в дашборде lalafo по умолчанию выключен (можно включить в фильтре «Источники»).
- **База** — сжатая (`realty.db.gz`) в ветке `data`; ветка перезаписывается одним коммитом, история не копится.
- **Дашборд** — Streamlit Community Cloud, файл `dashboard.py`. В настройках приложения (Secrets) задан
  `DATA_URL = "https://raw.githubusercontent.com/<владелец>/<репозиторий>/data/realty.db.gz"`.
  Дашборд перекачивает базу раз в 15 минут.
- Локально всё работает как раньше: если есть `data/realty.db`, дашборд берёт её.
- Чтобы забрать облачную базу на компьютер:
  `curl -L <DATA_URL> | gunzip > data/realty.db`
